# Alternador de Tema Claro e Escuro

Projeto desenvolvido durante meus estudos de desenvolvimento web para praticar a criação de interfaces e a manipulação de estilos com JavaScript.

## 🚀 Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

## ✨ Funcionalidades
- Alternância entre tema claro e escuro.
- Alteração dinâmica das cores da interface.
- Interação com o usuário por meio de JavaScript.

## 🎯 Objetivo
Praticar os fundamentos do desenvolvimento front-end e compreender como JavaScript pode modificar a aparência de uma página web.
